# QR-Code-Generator

Description

This project generates a QR code for a given URL using Python. The program uses the qrcode library to convert a website link into a scannable QR code image. In this example, the QR code is created for a GitHub profile and saved as a PNG image file.


Features

• Generate QR codes from any URL or text
• Save QR code as a PNG image
• Simple and beginner friendly Python project
• Useful for sharing websites, portfolios, GitHub profiles, or contact details

Technologies Used

• Python
• qrcode Library
